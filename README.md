
# 6-DOF Robotic Arm Pick-and-Place and Color Sorting

## About the Project
A robotics project focused on developing a 6-DOF robotic arm for pick-and-place operations and color-based object sorting.

## Hardware Components
- Arduino
- MG995 Servo Motors
- PCA9685 Servo Driver
- Ultrasonic Sensor
- Color Sensor
- Buck Converter
- 7.4V Battery

## Tools and Technologies
- Arduino IDE
- Embedded C/C++
- PWM Servo Control
- I2C Communication
- Sensor Integration

## Current Progress
- Mechanical assembly completed
- Servo motors tested
- Basic pick-and-place movement tested
- Ultrasonic sensor tested
- Color sensor connected; integration in progress

In Progress
