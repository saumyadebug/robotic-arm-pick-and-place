# Project Overview

The **Robotic Arm Pick and Place System** is an open-source, educational and industrial-prototype robotic arm designed to sort colored objects from a designated pickup area into target collection bins.

---

## Objectives
- Implement a 4-DOF articulated robotic arm with a gripper (6-DOF frame; wrist roll deferred).
- Integrate multi-sensor feedback (ultrasonic distance + optical RGB color sensing).
- Utilize I2C hardware PWM driver (PCA9685) to achieve jitter-free servo motion.
- Develop an autonomous finite-state machine (FSM) control loop.
- Deliver comprehensive documentation, calibration procedures, and testing data.

---

## Applications
- Automated industrial packaging and palletizing.
- Quality control and color-based reject sorting.
- Educational platform for robotics kinematics, embedded C++, and sensor fusion.
